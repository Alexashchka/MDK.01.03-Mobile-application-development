Экзамен (пробные варианты)

Библиотека сетевого слоя:

Необходимо разработать библиотеку сетевого слоя, реализующую классы с запросами RestAPI.
Библиотека должна содержать структуру классов, где все созданные классы и интерфейсы распределены на следующие папки:
1) datas – папка для запросов с RestAPI;
2) domains – папка для классов с моделями и логикой.

Библиотека UI-Kit:

Необходимо разработать библиотеку UI-kit, содержащую элементы графического интерфейса для пере-использования в основном приложении.
Элементы, разработанные в библиотеке, должны содержать метод init, устанавливающий первоначальные значения. Вся логика управления элементом (например отображение/скрытие пароля) должна быть реализована в обработчике графического элемента.

Основное приложение:

Разработать указанные в персональном варианте активности, с отображением информации. Использовать ранее разработанные библиотеки сетевого слоя и UI-kit.
Выполнить дополнительное задание, указанное в персональном варианте.
Приложение должно содержать структуру классов, где все созданные классы и интерфейсы распределены на следующие папки:
1) datas – папка для запросов с RestAPI;
2) domains – папка для классов с моделями и логикой;
3) presentations – папка для работы с классами, взаимодействующими с интерфейсом пользователя;
Реализовать сохранение указанной в индивидуальном варианте информации, полученной с сервера в SQLite, в случае отсутствия интернета, использовать информацию из базы данных.
